# Solar Cold Chain ☀️❄️

A web application for sustainable cold storage powered by solar energy.

## 🌍 Overview
Solar Cold Chain helps demonstrate how renewable energy can be used to maintain temperature-sensitive products efficiently, especially in remote areas.

## 🚀 Features
- Solar-powered cold storage concept
- Simple and interactive web interface
- Focus on sustainability and efficiency

## 🛠 Tech Stack
- HTML
- CSS
